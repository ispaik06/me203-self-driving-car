# ME203 Self-Driving Car Project

Autonomous driving car project for **ME203**.

This project implements:
- **Lane tracing** using a **CNN** (camera-based vision)
- **Traffic light classification** using a **CNN**
- **PID-based driving control** using **left/right ultrasonic sensors** for wall/spacing correction
